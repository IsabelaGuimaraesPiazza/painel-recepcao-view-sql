# Painel de Pacientes Prioritários com SQL Views

Este projeto simula uma necessidade real de sistemas hospitalares: criar uma visualização rápida e segura dos pacientes que precisam de atenção, protegendo dados sensíveis conforme as regras da LGPD.

# O Problema de Negócio
A tabela principal do hospital (`PRONTUARIOS`) mistura informações clínicas com dados pessoais confidenciais, como o CPF. A equipe da recepção precisa acompanhar apenas os pacientes em estado de atenção ou crítico, sem ter acesso aos documentos pessoais deles.
